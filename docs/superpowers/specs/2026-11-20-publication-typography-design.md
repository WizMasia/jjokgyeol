# T7 출판 양식과 제목 크기

## 저자가 할 수 있는 일

보고서 원고를 열어 본문을 나눔명조 11pt 진회색으로, 1단계 제목을 나눔고딕 18pt 굵은 남색으로 정한다. 본문을 16pt로 바꿔도 그 제목은 18pt다. 마크다운의 강조, 각주, 기관명 머리글과 쪽 번호가 들어간 지면을 미리 보고 같은 PDF를 받는다. 양식만 JSON으로 저장해 다른 원고에 쓸 수 있다.

## 선택한 방식

현재 양식은 본문 크기와 단계별 배율로 제목 크기를 계산한다. 계속 이 방식만 쓰면 기존 지면은 재현하기 쉽지만 본문만 바꾸는 편집에도 제목이 움직인다. 모든 파일을 독립 크기로 일괄 변환하면 예전 양식을 다시 편집할 때 동작이 달라진다. 사용자가 선택한 방식은 **새 양식의 제목 크기는 독립적으로 편집하고, 기존 파일은 종전 방식으로 여는 것**이다.

새 편집기를 열 때 출판 설정의 기본 본문 크기와 여섯 단계의 기존 배율로 초기 제목 크기를 한 번 계산한다. 각 단계의 크기를 정수 sp로 보관한다. 본문 크기를 바꾸거나 저장 양식을 다시 열어도 이 여섯 값은 그대로다. 기존 양식 파일과 API 요청에서 단계의 크기가 생략되면 그 단계에는 종전 배율을 사용한다. 예전 양식에서 한 단계만 명시적으로 고치면 다른 단계는 계속 비례한다. 열기와 다시 저장하기만으로 값이 생기지 않아야 한다. 저장된 구간별 제목 크기도 그대로 적용한다.

## 양식, 편집기와 PDF

- 기존 `Style`이 본문, 제목 1~6단계, 주, 단어 풀이의 글꼴·크기·색·굵기·기울임을 검증한다. 본문 글꼴·크기와 제목 공통 글꼴은 기존 필드를 사용한다. 굵기는 보통·굵게, 기울기는 바로·기울임을 제공한다. 기본값과 입력 한계는 출판 설정에서 읽고 실제 글꼴은 런타임에 고정된 파일을 쓴다. 기존 글꼴의 기울임과 굵은 기울임도 재사용한다.
- 새 역할별 속성은 선택 사항이다. 화면에는 pt와 %를 표시하고 파일에는 sp와 0.01% 단위 정수를 쓴다. 형식이나 범위를 위반하면 해당 필드를 알려 주고 편집 중 값과 직전 PDF를 보존한다. 기존 필드와 새 속성에 같은 뜻의 값을 중복 저장하지 않는다.
- 문서 공통 양식, 참고 문서에서 가져온 전체 역할 규칙, 구간 규칙 순으로 지정한 속성만 덮어쓴다. 본문 양식은 목록의 기본 글자 모양에도 적용한다. 목록의 표지 폭은 실제 적용한 글꼴과 굵기로 잰다. 원고에 표시한 굵은 강조·기울임, 각주의 참조 번호, 머리글·바닥글의 독자적인 규칙도 확인한다.
- 기존 세부 양식에 요소 선택과 해당 요소의 편집 값을 표시한다. 제목은 단계별로 지정한다. 양식 저장·열기, 미리보기·다운로드, 참고 서식 시험 적용·취소는 같은 검증 및 변환 경로를 쓴다. 오래된 파일에서 생략된 속성은 화면에 기본값을 보여 주더라도 사용자가 수정할 때만 저장한다.
- 기본 한글 자간, 최종 자간 하한·상한, 기존 어절 공백 하한·상한을 구분한다. 하한 ≤ 기본값 ≤ 상한을 원자적으로 검증한다. 최종 한계를 생략한 기존 양식은 현재 기본 자간으로 고정한다. T7은 이 값을 입력·저장·검증하고 T11에서 줄마다 허용 범위 안의 배치를 선택한다.
- 각주는 실제 지면에서 검사한다. 미주에도 주 양식을 적용하고 풀이를 작은 글자로 출력하는 인수는 T9의 원고 문법과 함께 진행한다. 양식 계약, 조판 결과, 아직 검사할 수 없는 역할은 각각 진행 기록에 남긴다.

독립 검토에서 확인한 세 가지 세부 동작은 다음과 같이 제안한다.

1. 참고 문서 분석은 현재 지원하는 글꼴·크기·색 등 기존 후보와 적용 대상을 유지한다. 굵기·기울임과 주·풀이 서식은 T7의 직접 편집에서 지정한다. 기존 후보 검토 화면은 현재 값과 시험 조판 결과에 새 문서 양식을 반영한다.
2. 풀이 크기는 저자가 지정한 값을 보관한다. T9에서 실제 본문이 작아져 그 값이 본문 크기 이상이 된 위치에는 출판 설정의 작은 글자 배율을 적용한다. 예컨대 10pt 풀이를 11pt 본문에서는 그대로 쓰고 9pt 본문에서는 9pt보다 작게 출력한다. 표시할 수 있는 양의 정수 sp가 없으면 해당 대목의 크기를 조정하도록 알린다.
3. 본문 속 각주 참조는 참조가 붙은 문구의 글꼴·색과 위 첨자 형태를 따른다. 쪽 아래의 각주 번호는 각주 본문의 글꼴·색·굵기·기울임과 기존 번호 배치를 사용한다. 주 양식이 생략된 예전 파일의 각주 본문과 번호는 기존 교정본을 기준으로 삼는다.

## 검증 기준

1. 새 편집기에서 본문 11pt→16pt, 1단계 제목 18pt, 다른 단계 하나의 크기, 각주 색·크기를 각각 검사한다. 같은 양식을 다시 열어 미리보기와 다운로드의 PDF 바이트가 일치하는지 본다. 원고 본문은 입력한 그대로여야 한다.
2. PDF에서 본문 `#222222`, 제목 `#17365D`, 일반·굵은 글꼴, 기울어진 강조, 크기와 쪽별 머리글·번호를 읽는다. 본문과 제목 글꼴이 같은 경우, 긴 목록 표지가 줄을 넘기는 경우, 같은 제목에 구간별 크기를 지정한 경우도 포함한다.
3. 기존 교정본과 같은 원고·양식으로 쪽수, 줄 텍스트, 글자 좌표·글꼴·크기를 비교한다. 이전 파일을 열고 저장한 뒤 본문만 바꿔 제목의 비례 동작을 확인한다. 양면 제본 및 참고 문서 적용 결과도 회귀 검사에 포함한다.
4. 잘못된 글자 크기·색·자간 범위, 본문 폭을 소진하는 여백은 화면과 API에서 동일하게 거부한다. 자간 기본값과 한계가 같은 경계, 반올림 전후의 유효성, 다른 속성을 건드리지 않는 부분 수정도 검사한다.

저장 키의 세부 구조, 편집 컨트롤의 배치와 테스트 표본 구성은 기존 인터페이스에 맞춰 구현자가 결정한다. 이후 작업은 [전체 개발 계획](../plans/2026-11-19-jjokgyeol-development.md)의 T9~T14 인수 기준을 따른다.
