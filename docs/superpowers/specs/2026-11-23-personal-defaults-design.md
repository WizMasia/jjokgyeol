# 새 문서의 출판 기본값

같은 종류의 원고를 쓸 때마다 양식 JSON을 다시 열어야 하는 수고를 줄인다. 웹 편집기와 네이티브 앱의 출판 설정에서 현재 양식을 다음 문서의 시작값으로 지정할 수 있다.

## 설정에서 할 수 있는 일

- **새 문서 기본값으로 저장**은 설정창에 보이는 출판 양식을 검증하고 저장한다. 판형과 여백, 글꼴, 제목과 본문 및 목록 단계별 서식, 문단 간격 등 기존 양식 JSON으로 저장할 수 있는 항목이 대상이다. 문서 글꼴은 기존 양식 파일처럼 참조를 보존하고 필요한 경우 다시 연결할 수 있다.
- **쪽결 기본값으로 복원**은 저장한 개인 기본값을 지운다. 다음에 편집기를 열면 쪽결의 기본 양식과 보고서형 목록으로 시작한다. 두 동작 모두 성공 여부를 설정창에 표시한다.
- **적용**은 현재 원고에 대한 동작을 유지한다. 개인 기본값 관리와 현재 문서·양식 파일의 저장 상태를 독립적으로 처리한다.

## 적용 시점과 저장 위치

첫 미리보기를 만들기 전에 개인 기본값을 읽는다. 웹은 같은 브라우저 프로필과 사이트 주소에서, 네이티브는 같은 사용자 계정의 쪽결 앱에서 재실행 후에도 읽을 수 있어야 한다. 웹과 네이티브의 설정창은 같은 양식 저장·열기 검증과 정수 저장 형식을 사용한다. 원고 본문, 교정 PDF, 외부 모델 접속 정보와 API 키는 개인 양식의 범위 밖이다.

저장된 `.jjok`과 사용자가 명시적으로 여는 양식 JSON은 각 파일의 서식과 예전 파일의 생략값 해석을 우선한다. 이미 작업 중인 편집기에서 Markdown 원고를 열거나 가져올 때는 현재 양식을 쓰는 기존 흐름을 따른다. 기본값 읽기가 늦어져도 이후 사용자가 연 파일이나 수정한 서식을 덮어쓰지 않는다.

## 방식 선택과 검증

설정의 모든 변경을 자동으로 기억하면 일회성 조정까지 따라간다. 명시적으로 기본값을 저장하는 방식을 추천한다. 여러 양식을 보관하거나 다른 기기로 옮길 때는 기존 양식 JSON 열기·저장을 이용할 수 있다.

웹 새로고침과 네이티브 재실행, 첫 미리보기, 개인 기본값 복원, 이전 문서 열기를 확인한다. 잘못된 값이나 저장 공간 오류가 발생하면 사용자에게 알리고 기존의 유효한 기본값을 보존한다. 읽을 수 없는 기본값이 있어도 쪽결 기본 양식으로 편집기를 열 수 있어야 한다.
