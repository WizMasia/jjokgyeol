# 일반 보고서 양식

‘양식 열기’로 불러오는 독립 JSON 파일에 A4 판형과 기존 기본 여백, 제목 및 목록 양식을 담는다. 원고는 첫 단계 제목(#)과 중첩 마크다운 목록을 사용한다. 제목은 본문 폭의 검은 사각형 안에 가운데 정렬하고, 긴 제목은 틀 안에서 줄을 나눈다. 제목과 1단계는 배포 이미지의 OFL 나눔고딕 Bold, 2·3단계는 나눔명조, 4단계는 나눔고딕 보통을 사용한다.

| 위치 | 기호 | 글자 크기 | 기호 시작 위치 |
| --- | --- | --- | --- |
| 제목 | 사각형 틀 | 20pt | 가운데 |
| 1단계 | □ | 16pt | 왼쪽 0pt |
| 2단계 | ○ | 15pt | 7.5pt |
| 3단계 | 굵은 하이픈(-) | 15pt | 22.5pt |
| 4단계 | 별표(*) | 13pt | 37.5pt |

3단계의 미지정 크기는 2단계와 같게 잡는다. 한 칸은 15pt 글자의 반각인 7.5 TeX pt로 통일하고, 모든 단계를 본문 왼쪽 경계에서 잰다. 목록 본문의 이어지는 줄은 항목 첫 글자에 맞춘다. 기존 양식의 부모 기준 들여쓰기는 파일에 새 옵션을 지정했을 때만 바뀐다. 제목·본문 내용은 별도의 예제 원고에 둔다.
