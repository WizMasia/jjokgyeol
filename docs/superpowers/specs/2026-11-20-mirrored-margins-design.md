# 양면 보고서의 안쪽·바깥쪽 여백과 제본 여백

왼쪽으로 제본하는 보고서에 문서 전체의 안쪽·바깥쪽·제본 여백을 지정한다. 표지를 포함한 실제 PDF 1쪽을 홀수로 세며, 본문이 다음 쪽으로 밀리면 본문과 쪽 번호가 그 면의 같은 좌우 경계를 사용한다.

## 여백 계산과 선택한 방식

저자는 **안쪽 여백에 제본 여백을 더하는 방식**을 선택했다. 안쪽 12mm와 제본 6mm이면 종이의 제본 쪽 가장자리에서 본문까지 18mm다. 두 값을 따로 저장하므로 같은 원고를 두꺼운 책으로 낼 때 제본 여백만 늘릴 수 있다. 함께 검토한 다른 방식은 안쪽 12mm에 제본 6mm를 포함하는 방식이었다. 그 방식에서는 같은 입력으로 본문이 제본선에서 12mm에 시작해 본문 폭과 줄바꿈이 달라진다.

| 실제 면 | 왼쪽 여백 | 오른쪽 여백 | 바깥쪽 번호 위치 |
|---|---|---|---|
| 홀수 | 안쪽 + 제본 | 바깥쪽 | 오른쪽 본문 경계에 번호 끝을 맞춤 |
| 짝수 | 바깥쪽 | 안쪽 + 제본 | 왼쪽 본문 경계에 번호 시작을 맞춤 |

본문 폭은 모든 쪽에서 `판형 폭 − 안쪽 − 제본 − 바깥쪽`이다. 위·아래 여백은 기존 값을 사용한다. 본문, 제목, 목록의 들여쓰기, 각주, 머리글·바닥글의 세 칸은 같은 본문 사각형을 기준으로 놓는다. 기존 양식의 ‘홀수 오른쪽·짝수 왼쪽’ 번호 규칙을 그대로 쓸 수 있다. 첫 면에서 머리글이나 번호를 숨기는 설정은 본문 여백이나 홀짝 순서에 영향을 주지 않는다.

## 편집·저장

- **판형·여백**에서 ‘고정 좌우 여백’과 ‘양면 여백’을 선택한다. 새 설치의 초기값과 기존 양식 파일은 고정 좌우 여백을 쓴다. 고정 양식을 그대로 열고 저장하면 기존 JSON 필드와 인쇄 결과를 보존한다.
- 고정에서 양면으로 처음 바꿀 때 기존 왼쪽 값을 안쪽으로, 오른쪽 값을 바깥쪽으로 가져오고 제본 여백은 0으로 시작한다. 사용자는 세 값을 mm로 수정하고 실제 안쪽 합계와 본문 폭을 확인한다. 양면에서 고정으로 전환하면 홀수 면의 실제 왼쪽·오른쪽 여백을 사용한다.
- 같은 편집 화면에서 모드만 왕복했다면 마지막 안쪽·바깥쪽·제본 입력을 복원한다. 고정 모드에서 좌우 치수를 직접 바꾸거나 참고 문서에서 다른 좌우 치수를 적용했다면 새 치수를 기준으로 제본 0부터 시작한다. 고정 양식 파일을 새로 연 경우에도 파일의 좌우 치수를 따른다.
- 화면은 mm, 저장은 기존 정수 sp 단위를 사용한다. 양면 양식에서는 안쪽과 제본 값을 다시 나눌 수 있도록 각각 저장한다. 설치 기본값은 출판 설정에서 읽는다. 참고 문서의 기존 ‘위·오른쪽·아래·왼쪽’ 후보에는 안쪽과 제본의 구분이 없다. 이 후보는 고정 좌우 모드에서 적용할 수 있음을 표시한다. 양면 모드에서도 머리글·바닥글 등 다른 참고 후보는 그대로 적용할 수 있다.
- 저장 계약은 선택적 정수 필드 `gutter_sp`로 두 모드를 구분한다. 필드가 없으면 기존 고정 양식이고, 0을 포함해 값이 있으면 양면 양식이다. 양면에서 `margins_sp`의 네 값은 위·바깥쪽·아래·안쪽 순이며 안쪽 값은 제본분을 더하기 전 치수다. 조판 시 제본분을 한 번 더한다. 제본 0인 양면 양식도 다시 열면 홀짝 교대가 유지된다.
- 여백은 각각 0 이상이어야 하고 합산 후 본문과 들여쓴 줄에 사용할 폭이 남아야 한다. 화면·저장·조판에서 같은 검증을 적용한다. 잘못된 입력은 해당 필드에 표시하고 직전 정상 미리보기를 유지한다.

## 미리보기와 PDF 인수 기준

기존 128 × 100mm 표본에 안쪽 12mm·제본 6mm·바깥쪽 10mm를 지정한다. 기존 고정 여백 14mm + 14mm와 가로 여백의 합이 같아 본문 폭이 100mm로 유지된다. 두 원고의 유일한 차이는 중간에 추가한 열 문단이다. [추가 전 원고](../../../proofs/running-heads/before.md) · [추가 후 원고](../../../proofs/running-heads/after.md) · [기존 양면 표본](../duplex-running-heads-acceptance.md)

| PDF 실측 항목 | 추가 전 9쪽 · 홀수 | 추가 후 10쪽 · 짝수 |
|---|---|---|
| 전체 쪽수 | 11 | 12 |
| ‘추적문장 파도 끝에서 푸른 유리 조각을 찾았다.’ 첫 글자의 왼쪽 끝 | 종이 왼쪽에서 18mm (51.024 PDF pt) | 종이 왼쪽에서 10mm (28.346 PDF pt) |
| 유일한 바닥글 번호의 바깥 모서리 | ‘9’ 오른쪽 끝, 종이 왼쪽에서 118mm (334.488 PDF pt) | ‘10’ 왼쪽 끝, 종이 왼쪽에서 10mm (28.346 PDF pt) |

브라우저에서 양면 여백을 입력하고 미리보기를 갱신한 뒤 두 PDF를 내려받는다. 각 원고에서 미리보기와 다운로드의 바이트가 같은지 확인한다. PDF 글리프 좌표의 허용 오차는 0.04 PDF pt다. 각 쪽의 본문·각주는 같은 원고의 기존 PDF와 비교해 줄바꿈·세로 좌표가 일치하고 가로 위치가 홀수 +4mm, 짝수 −4mm인지 확인한다. 표지 번호 숨김, 번호 중복 여부, 양식 저장·재개방, 제본 0, 본문 폭을 소진하는 입력, 고정 좌우 여백이 서로 다른 기존 양식도 검사한다. 결과로 9쪽과 10쪽을 나란히 담은 비교 PDF를 제공한다.
