# 판형·들여쓰기·법령 옵션 인수

1. 출판 정책의 판형 목록을 편집기의 판형 폭·높이에 연결한다. 목록 선택, 직접 편집, 양식 열기의 동기화를 테스트한다.
2. 기존 편집·검증·저장 단위를 유지하면서 들여쓰기 단위 전환과 pt 입력을 구현한다. 다시 열기, 여백 방식 전환, sp 경계와 잘못된 입력을 테스트한다.
3. 조 제목 설정을 법령 옵션에 모은다. 일반 원고의 기본 화면, 활성화·해제, 예전 양식 열기, 번호 고정과 양식 오류에서의 복귀를 검사한다.
4. 실제 브라우저에서 판형과 단위를 바꾸어 PDF 판형·들여쓰기 좌표와 정수 양식 파일을 확인한다. 서비스에 반영하고 비공개 원격과 결과를 대조한다.
