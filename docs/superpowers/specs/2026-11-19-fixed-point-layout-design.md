# 자간과 공백의 정수 연산 및 저장

**확정 사항** — 자간·공백 비율은 0.01%를 한 단위로 하는 부호 있는 정수로 저장한다. 저자는 양식에 평소처럼 %를 입력한다. −7.25%는 `-725`, 70~130%는 `[7000, 13000]`이다.

**표현 방식 선택** — 분자와 분모를 따로 저장하면 임의의 비율을 표현할 수 있다. 쪽결에서 선택한 고정소수점 방식은 모든 비율의 분모가 10000이어서 기본 자간과 줄별 보정의 합산, 상하한 비교, 저장 후 재개방에 정수 하나면 충분하다.

## 구현 기준

- **입력과 저장.** 기존 API의 `ko_tracking_pct`, `space_pct`는 계속 % 단위로 읽는다. 브라우저 입력과 JSON 숫자의 십진 표기에서 직접 정수로 변환한다. 내부 JSON에는 단위가 드러나는 `ko_tracking_per_10000`, `space_per_10000` 필드를 쓴다. 원래 입력의 유효 범위를 먼저 검사한다. 정밀도를 초과한 기존 값은 가장 가까운 0.01%로 한 번 반올림하며, 정확히 절반이면 0에서 먼 쪽을 택한다. 새 입력도 같은 규칙을 쓰고 양식 창에 적용값을 보여 준다. 예를 들어 −7.245%는 −7.25%가 된다.
- **길이.** 판형·여백·글자 크기·행간은 입력 단위인 mm·pt에서 TeX의 정수 길이 `sp`로 한 번 환산한다. 1 TeX pt는 65536sp다. 전각 공백과 어절 공백에는 해당 글꼴의 실제 기본 폭을, 자간에는 해당 글자의 크기를 기준으로 쓴다. PDF에서 읽은 소수 좌표는 출력 검증에 사용한다.
- **나눗셈.** 줄마다 실제 시작 좌표에서 출발한다. 자간을 적용할 때마다 `글자 크기(sp) × 자간 비율 정수`를 누적하고, 누적 분자를 10000으로 나눈 값을 가장 가까운 정수로 반올림한다. 이웃한 두 누적 결과의 차이가 해당 간격에 적용할 보정량이다. 공백도 해당 공백의 기본 폭으로 계산한다. 각 줄바꿈 후보를 평가할 때와 선택된 줄을 출력할 때 같은 계산을 사용하고, 확정한 간격은 조판기에 한 번만 적용한다.

## 인수 기준

1. 기존 API의 `-7`과 `[70, 130]`을 읽으면 내부 JSON에 `-700`과 `[7000, 13000]`이 저장된다. 저장·재개방을 반복해도 정수값이 동일하다.
2. 11pt에서 −7%를 적용한 간격 100개의 누적 보정은 정확히 −5,046,272sp다. 첫 줄 들여쓰기와 내어쓰기로 줄 시작점이 바뀌는 원고에서도 각 줄의 실측 폭과 후보 판정이 일치한다.
3. 기존 한영 혼합 원고로 제목·본문 자간, 영문 내부 간격, 공백 상하한, 전각 들여쓰기를 다시 측정한다. Docker 편집기에서 미리보기와 내려받은 PDF의 바이트가 일치해야 한다.

어절 전체가 다음 줄에 들어갈 때도 읽기 편의를 위해 내부 개행을 허용할지는 별도의 양식 정책으로 결정한다.
