# 판독 안내 / Reader instructions

폴더의 `reading-sheet.csv`를 복사해 UTF-8 CSV로 작성한다. ID 열을 텍스트로 열고 표 순서대로 같은 `group`의 PDF를 모두 읽는다. `sample`이 파일 이름이다. 같은 화면·배율이나 같은 용지·실제 크기 인쇄를 끝까지 유지한다. 파일 속성이나 대응표는 열람하지 않는다.

- `preferred` — 그 묶음에서 가장 읽기 편한 표본 전부에 `1`, 나머지에 `0`을 쓴다. 모두 동등하면 모두 `1`이다.
- `crowding` — 글자가 붙어 보이는 쪽과 실제 문구를 적는다. 없으면 `none`이다.
- `paragraph` · `reason` — 손볼 문단을 처음부터 1로 세어 적고, 무엇을 왜 고칠지 적는다. 여러 문단은 `1,3`처럼 쓰고 이유에 번호를 붙인다. 수정할 곳이 없으면 두 칸 모두 `none`이다.
- 같은 묶음의 `ref-그룹ID.pdf`가 있으면 그 기준 지면과 각 표본을 대조해 남은 수정 대목을 기록한다. 기준 지면에는 표를 주지 않는다.
- 전체 표를 작성해 진행자에게 전달한다. 진행자가 익명 별칭으로 한 번 등록한다.

**English.** Read each group in sheet order on the same medium. Mark all joint favourites. For each sample, quote crowded text with its page and give paragraph numbers and reasons for remaining edits. Compare with the group reference when supplied. Use `none` for observations you checked and did not find.
