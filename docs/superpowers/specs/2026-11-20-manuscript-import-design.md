# T10 원고 가져오기

`app.importers.read.import_file(name: str, data: bytes) -> ImportResult`는 이름의 확장자로 판독기를 고른다. 성공 시 `markdown: str`, `warnings: list[str]`를 돌려주고 실패 시 `ValueError`를 낸다. 입력 바이트와 편집 상태는 읽기 전용이다. 총괄이 HTTP 요청 제한·작업자 격리·기한과 새 원고 열기를 연결한다.

- TXT는 UTF-8(BOM 포함)·ASCII의 줄과 빈 줄을 보존한다. HTML은 제목, 문단, 목록, 강조와 링크의 문구·주소를 옮긴다. 그림은 위치를 알리는 경고를 남긴다. 외부 주소를 열지 않는다.
- DOCX·HWPX는 기존 참고 문서 모듈의 DTD 금지 XML 판독과 패키지 관계 해석을 사용한다. 본문을 저장 순서로 읽고 머리글·바닥글·자동 쪽 번호를 제외한다. 제목·번호·글머리표 종류와 깊이, 글자 구간별 굵기·기울기를 마크다운으로 옮긴다.
- HWP 5는 로컬 olefile 0.47로 복합 파일을 열고 FileHeader, DocInfo, BodyText/SectionN을 읽는다. 문단·글자 모양 인덱스와 UTF-16 위치를 적용한다. 암호·배포용 파일은 오류로 돌려준다. 표의 셀 본문을 보존하고 표 배치와 그림의 손실을 알린다.
- 목록에서 부모 단계가 비면 직전 항목 바로 아래에 붙이고 원래 깊이와 변환 깊이를 알린다. 같은 원본 깊이의 형제는 같은 깊이를 유지한다. 마크다운 제목은 최대 6단계로 제한하고 축소를 알린다.
- 입력·압축 해제 총량·엔트리·결과 크기·구조 개수에 한도를 둔다. 파일 시스템에 원문을 풀지 않는다. ZIP 경로 중복, 암호화, 손상, 과대 압축은 실패다. 가져오기 전용 한도는 한 설정 파일에서 읽는다.
- 공개 원본과 저장소 증빙의 해시를 고정한다. 원본에서 읽은 내용과 새 원고를 다시 연 구조를 비교한다. 외부 변환기 설치·실행 없이 오프라인 Linux 이미지에서 재현한다.

사용자가 추천안 결정을 위임했다. 기존 ZIP/XML 판독기를 재사용하고 HWP 컨테이너 의존성만 고정하는 안을 채택했다. 원본·대조 기준은 [전체 계획 마지막 표](../plans/2026-11-19-jjokgyeol-development.md)에 따른다.

### 새 원고를 다시 열 때

- TXT 줄과 HTML·Office 문단에 실제로 적힌 별표, 밑줄, 대괄호, 역슬래시는 마크다운 이스케이프로 보존한다. 줄 첫머리의 `1.`, `2)`, `#`, `-` 등은 원본에서 목록이나 제목으로 지정한 경우에만 구조 표지가 된다. 편집기는 원고 문법에 쓰이는 구두점 앞의 역슬래시만 해석한다. 기존 원고의 `\%`, 엔티티와 HTML 태그는 계속 글자로 읽는다.
- 굵기·기울기는 별표와 밑줄 구분자로 기록한다. 인접 구간의 글자와 서체를 다시 읽어 대조한다. 예를 들어 낱말 안쪽의 구두점에서 구분자를 열 수 없으면 원문 글자를 모두 보존하고 표현 가능한 강조와 손실 위치를 남긴다. HTML 링크는 `[문구](주소)`로 저장한다.
- HWP·HWPX의 본문 표·그림 캡션에는 저장된 자동 번호와 접두·접미 문자를 넣는다. 자동 쪽 번호는 제외한다. 숫자 표시 모양을 십진수로 단순화하면 원본 위치와 함께 알린다.
- HTML 목록 항목 안의 다음 문단은 같은 항목의 계속 문단이다. 자식 목록을 닫은 뒤의 글도 원래 부모 항목에 속한다. DOCX는 해당 목록 인스턴스에 지정한 단계별 재정의를 반영한다.
- HTML 그림 경고는 원본의 행·열을 가리킨다. Office 개체와 단계 변경 경고는 원본의 표 또는 본문 문단을 가리킨다. 제외된 개체 안의 표는 변환한 셀로 집계하지 않는다.
