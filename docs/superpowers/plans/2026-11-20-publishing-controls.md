# 판형·들여쓰기·법령 옵션 인수

1. 출판 정책의 판형 목록을 편집기의 판형 폭·높이에 연결한다. 목록 선택, 직접 편집, 양식 열기의 동기화를 테스트한다.
2. 기존 편집·검증·저장 단위를 유지하면서 들여쓰기 단위 전환과 pt 입력을 구현한다. 다시 열기, 여백 방식 전환, sp 경계와 잘못된 입력을 테스트한다.
3. 조 제목 설정을 법령 옵션에 모은다. 일반 원고의 기본 화면, 활성화·해제, 예전 양식 열기, 번호 고정과 양식 오류에서의 복귀를 검사한다.
4. 실제 브라우저에서 판형과 단위를 바꾸어 PDF 판형·들여쓰기 좌표와 정수 양식 파일을 확인한다. 서비스에 반영하고 비공개 원격과 결과를 대조한다.

## 인수 기록

배포 편집기에서 A4를 고르고 첫 줄 11pt, 이후 줄 22pt를 입력했다. 모델 선택이 실제 적용된 비교 응답에서 두 PDF의 폭과 높이는 210×297mm였다. 왼쪽 여백 18mm를 포함한 글자 시작점은 첫 줄 21.866mm, 이후 줄 25.732mm였다. 양식 파일에는 720896sp와 1441792sp가 저장됐다. 단위만 바꾼 뒤의 양식과 다시 연 양식이 일치했다.

종전 법령 견본과 출판 서식 견본을 변경 전후에 각각 조판해 모든 글자와 좌표가 일치하는지 확인했다. 일반 원고에서는 조 제목 설정과 번호 고정 단추가 숨겨지고 법령 옵션을 열면 사용할 수 있다. 활성 양식을 다시 열었을 때 조문 번호와 마크다운의 고정 표시가 유지됐다.

390px와 1360px 화면에서 판형 선택, 들여쓰기 단위, 법령 옵션이 화면 폭 안에 표시됨을 확인했다. 설치된 앱 파일 52개의 해시가 Git과 일치했다.

최종 테스트 이미지 68개 모듈에서 1,046건이 통과했고 환경 의존 검사 60건은 이 실행에서 건너뛰었다. 별도 서비스·브라우저 검사 11건과 실제 사용 주소의 모델·규칙 PDF 검사가 통과했다.
