# 일반 보고서 양식 구현 계획

Superpowers subagent-driven-development와 TDD로 [양식 설계](../specs/2026-11-20-general-report.md)를 구현한다. 기존 Style 모델, LuaLaTeX 조판기, HTML 편집기의 저장·열기 흐름을 사용한다.

- [x] 제목에 한해 선택 속성 `text_styles.heading1.frame="box"`를 검증·저장하고 PDF에서 사각 테두리와 다행 제목을 검사한다. 기본 제목의 지면과 각주도 확인한다.
- [x] 목록 단계에 선택 속성 `font`, `font_pt`(저장 시 `font_sp`), `weight`, `mark_weight`, `indent_origin="margin"`을 지원한다. 목록 본문·표지에 반영하고 원래의 들여쓰기, 양식 파일 왕복과 입력 검증을 검사한다.
- [x] `proofs/general-report/`에 예제 원고와 출력 PDF를 둔다. 배포할 양식 원본은 편집기에서 다운로드할 수 있게 `app/static/general-report.json`에 둔다. 호스트 Chromium으로 열고 저장한 JSON을 원본과 비교하고, 다운로드 PDF의 글꼴·크기·기호·위치를 설계와 독립적으로 측정한다. 최종 이미지 회귀와 검토 뒤 사용법을 기록하고 비공개 저장소에 푸시한다.

## 출력 검증

배포 이미지의 편집기에서 양식을 내려받아 열고, 다시 저장한 JSON의 모든 값을 원본과 대조했다. 예제 원고의 바이트도 열기 전후에 일치했다. 실제로 다운로드한 [예시 PDF](../../../proofs/general-report/general-report.pdf)는 A4 한 쪽이다. 본문 왼쪽 경계는 PDF 좌표 51.02pt이고, 제목의 위아래 테두리는 x=51.02~544.25pt이다.

| 위치 | PDF에 포함된 글꼴 | TeX 글자 크기 | 기호 왼쪽 x (PDF pt) |
| --- | --- | --- | --- |
| 제목 | NanumGothicBold | 20pt | 가운데 |
| □ | NanumGothicBold | 16pt | 51.02 |
| ○ | NanumMyeongjo | 15pt | 58.50 |
| - | NanumMyeongjoBold, 본문은 NanumMyeongjo | 15pt | 73.44 |
| * | NanumGothic | 13pt | 88.38 |

참고 서식 화면에서 목록 단계별 글꼴이나 크기가 서로 다르면 ‘단계마다 다름’으로 표시한다. 모든 단계에 같은 값이 적용되면 실제 공통 값을 표시하고, 선택한 구간에 별도 규칙이 있으면 그 값을 표시한다.

65×77mm에서 여섯 줄 제목이 첫 쪽에 들어가고 뒤 목록은 다음 쪽의 아래 여백 안에 놓였다. 90×82mm에서 앞선 네 문단 뒤의 짧은 제목·첫 목록 항목·제목 각주는 함께 다음 쪽으로 넘어갔다. 네모 틀을 쓰지 않는 양식의 쪽 나눔은 기존 조판 경로를 따른다.

최종 Linux ARM64 테스트 이미지에서 58개 모듈을 네트워크 없이 실행했다. 총 925개가 통과했고 운영자 연결 등 외부 조건이 있는 57개가 건너뛰어졌다. Starlette TestClient 의존성 폐기 예정 경고가 1건 있었다.

호스트 Chromium·로컬 서비스 인수는 두 묶음에서 각각 27개와 30개가 통과했다. 양식 다운로드부터 PDF 저장까지의 검사 1개를 두 포트에서 반복해 고유 검사는 56개다. 기존 양식의 글자 좌표·줄바꿈 대조, 참고 서식 가져오기, 실모델 및 고정된 후보 묶음 검사도 포함했다.
