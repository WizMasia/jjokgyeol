# 출판 양식 조작

판형 목록은 A4(210×297), A5(148×210), A6(105×148), 신국판(152×225), 사륙판(128×188), 사륙배판(188×257)과 직접 입력을 제공한다. 치수는 세로 기준 mm다. 새 원고의 A5, 편집·불러오기·참고 양식에서 받은 사용자 치수를 현재 선택에 반영한다. 목록과 실제 치수는 설치한 출판 정책을 공유한다. 국내 판형은 재단 크기로 표기한다. [북토리 판형 안내](https://www.booktory.com/make-guide/pg1-1.asp?gnb=1&lnb=1) · [바른프린팅 인쇄 가이드](https://www.brprint.co.kr/guide/bsc-01.asp)

첫 줄과 이후 줄 들여쓰기의 표시·입력 단위를 mm 또는 본문 글자 크기와 같은 TeX pt로 전환한다. 예를 들어 본문 11pt에서 11pt를 입력하면 본문 크기 한 개에 해당하는 고정 길이다. 단위를 바꿀 때 저장된 지면, 원고와 양식의 편집 상태를 보존한다. 새 화면은 mm로 시작하며 양식은 기존 정수 sp 형식을 쓴다.

법령 문서 옵션은 출판 양식에서 별도로 열 수 있다. 일반 문서에서는 조문 번호와 번호 고정 조작을 감춘다. 활성화된 예전 양식을 열면 필요한 조작을 사용할 수 있고, 세부 옵션을 닫는 것과 저장할 조문 번호를 끄는 동작을 구별한다.
