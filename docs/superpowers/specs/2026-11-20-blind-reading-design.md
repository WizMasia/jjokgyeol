# T14 사람 판독 사전 규약 / Blind reading protocol v1

총괄이 위임한 1안은 로컬 CSV와 실행별 보관함이다. 기존 편집 화면과 서버를 수정하지 않고 같은 렌더 API를 사용한다. 독립 검토는 총괄이 인계 뒤 맡는다.

- **원고와 단위** — 프로젝트에서 새로 작성한 혼합 산문 3편을 원고 단위로 고정한다. 자간 탐색 1편, 모델 비교 2편이다. 외부 기고·개인정보·사람 동의 기록은 없다. T13은 학습·튜닝에 사용한 전체 로컬 원고 목록을 제공해야 한다. 같은 작품 그룹, 유니코드·공백 정규화 후 같은 원고 또는 같은 문단의 교차 사용을 거부한다. 관련 개작은 같은 작품 그룹을 유지한다.
- **자간 실험** — 같은 본문으로 나눔명조·고딕 × 11/16pt × 0/−3/−7%를 만든다. A5, 상하 20mm·좌우 18mm, 행간 17/24pt, 어절 공백 100%, 줄별 자간 보정 끔. 글꼴·크기별 세 장을 한 묶음으로 읽는다. 실제 본문에서 인접 한글과 영문 간격을 검사한다.
- **모델 실험** — 두 원고 모두 A5·명조 11/17pt, 기본 자간 0%, 공백 70~130%로 고정한다. 편집자가 같은 원고·글꼴·판형에서 직접 지면을 고치고 문단·사유와 PDF를 매번 남긴다. 만족한 판을 명시적으로 확정한다. 고정 기준 지면 두 개를 먼저 확보한다. 같은 조건으로 실제 규칙과 모델이 각각 선택한 두 PDF를 받는다. 누락·규칙 복귀·같은 지면이면 전체 실행을 보류한다. 원고별 선택적 제외는 없다.
- **눈가림 / Blinding** — 두 실험은 별도 실행이다. 원고별 묶음과 묶음 안 열람 순서를 매번 섞는다. 파일·표에는 무작위 실행·묶음·표본 ID만 쓴다. 조판 원본은 운영자만 보관하고 열람본은 원래 판형의 300dpi 무손실 이미지 PDF로 통일한다. 식별 가능한 문서 속성·내장 글꼴을 제거한다. 편집자 기준 지면은 같은 방식으로 열람한다.
- **사람 판독 / Ballot** — 실행마다 대응표를 모르는 판독자 한 명이 같은 매체·배율에서 비교한다. 가장 읽기 편한 표본 전부에 1, 나머지에 0을 적는다. 모델 쌍의 두 표가 모두 1이면 동률이다. 각 표본에서 붙어 보이는 쪽·문구와 손볼 문단 번호·사유를 적는다. 모델 쌍은 기준 지면과 대조한다. 해당 없음도 명시한다. 응답 원본·평가자 별칭을 제출 후 고정한다.
- **채택 / Deployment** — 두 모델 쌍의 완전한 판독에서 모델 승수가 규칙 승수보다 많고, 양쪽 합산 제약 위반과 선택 줄/PDF 줄 불일치가 모두 0이며, 사용자가 실측 갱신 시간을 수용할 때만 기본 활성화를 제안한다. 동률은 어느 쪽에도 가산하지 않는다. 시간은 호출 직전부터 PDF 수신까지의 벽시계 ms로 측정하고 조건별 n·최소·중앙·최근접 순위 p95·최대를 보고한다. 표본이 적어 이 실행의 기술통계만 제시한다. 사람 판독 전에는 품질 및 채택 판정을 유보한다.
