# 새 문서의 출판 기본값

같은 종류의 원고를 쓸 때마다 양식 JSON을 다시 열어야 하는 수고를 줄인다. 웹 편집기와 네이티브 앱의 출판 설정에서 현재 양식을 다음 문서의 시작값으로 지정할 수 있다.

## 설정에서 할 수 있는 일

- **새 문서 기본값으로 저장**은 설정창에 보이는 출판 양식을 검증하고 저장한다. 판형과 여백, 글꼴, 제목과 본문 및 목록 단계별 서식, 문단 간격 등 기존 양식 JSON으로 저장할 수 있는 항목이 대상이다. 문서 글꼴은 기존 양식 파일처럼 참조를 보존하고 필요한 경우 다시 연결할 수 있다.
- **쪽결 기본값으로 복원**은 저장한 개인 기본값을 지운다. 다음에 편집기를 열면 쪽결의 기본 양식과 보고서형 목록으로 시작한다. 두 동작 모두 성공 여부를 설정창에 표시한다.
- **적용**은 현재 원고에 대한 동작을 유지한다. 개인 기본값 관리와 현재 문서·양식 파일의 저장 상태를 독립적으로 처리한다.

## 적용 시점과 저장 위치

첫 미리보기를 만들기 전에 개인 기본값을 읽는다. 웹은 같은 브라우저 프로필과 사이트 주소에서, 네이티브는 같은 사용자 계정의 쪽결 앱에서 재실행 후에도 읽을 수 있어야 한다. 웹과 네이티브의 설정창은 같은 양식 저장·열기 검증과 정수 저장 형식을 사용한다. 원고 본문과 교정 PDF는 개인 양식의 범위 밖이다.

저장된 `.jjok`과 사용자가 명시적으로 여는 양식 JSON은 각 파일의 서식과 예전 파일의 생략값 해석을 우선한다. 이미 작업 중인 편집기에서 Markdown 원고를 열거나 가져올 때는 현재 양식을 쓰는 기존 흐름을 따른다. 기본값 읽기가 늦어져도 이후 사용자가 연 파일이나 수정한 서식을 덮어쓰지 않는다.

## 설정에서 선택하는 AI 모델

웹과 네이티브의 설정창에 **AI 모델 설정**을 표시한다. 기존의 규칙 조판, 내장 모델, 외부 API 선택과 다섯 API 형식을 활용한다. 외부 API는 형식, 서버 주소, 모델 ID와 필요한 경우 API 키를 받는다. 공급자 목록의 Ollama 바로 다음에 LM Studio를 둔다. LM Studio를 선택하면 편집 가능한 로컬 기본 주소를 제시하고 OpenAI 호환 API를 사용한다. 모델 ID는 항상 텍스트로 직접 입력할 수 있다. **모델 목록 조회**를 누르면 선택한 공급자·주소와 현재 입력한 키로 모델 목록을 요청한다. 조회는 모델명 없이 가능하다. 목록에서 고른 ID는 입력란에 채워지고 다시 편집할 수 있다. 조회 실패 또는 빈 목록은 직접 입력한 값을 보존한다. 연결이 바뀌거나 창이 닫힌 뒤 도착한 응답은 버린다. 목록 조회는 추론을 실행하지 않는다. 사용자 기본값이 없는 새 편집기는 규칙 조판으로 시작한다. 운영자가 고정해 둔 모델은 해당 설치에서 명시적으로 선택할 수 있고, 고정 모델 평가용 API 호출은 종전의 재현 조건을 유지한다.

웹의 **AI 양식 제안**은 기본 주소와 모델명 상수를 제거하고 설정에서 적용한 외부 API 연결로 요청한다. 실행 전에 요청 문구와 현재 양식 값이 어느 모델로 전송되는지 볼 수 있게 한다. 양식 제안을 지원하는 외부 연결이 없으면 설정으로 안내한다. 주소·모델·키가 유효하지 않아도 다른 모델에 재시도하지 않는다. 내장 결정 모델은 측정 후보 선택에 사용한다. 기존에 별도 운영자 설정을 쓰고 기본 주소가 비어 있는 스캔 판독, 네이티브에 새 양식 제안 기능을 추가하는 일은 이 변경의 범위 밖이다.

설정에서 기본값 저장을 선택하면 AI 방식과 비밀이 없는 서버 주소, API 형식, 모델 ID를 기기 내 설정으로 기억한다. API 키는 기존 승인대로 현재 실행 세션 메모리에서만 사용한다. 외부 연결을 문서나 양식 JSON으로 내보내지 않는다. 저장과 설정창 열기로 모델 호출을 발생시키지 않는다. 연결 확인과 실제 조판·양식 제안은 같은 연결 검증을 거치고, 주소 변경 시 이전 키를 비운다.

## 방식 선택과 검증

설정의 모든 변경을 자동으로 기억하면 일회성 조정까지 따라간다. 명시적으로 기본값을 저장하는 방식을 추천한다. 여러 양식을 보관하거나 다른 기기로 옮길 때는 기존 양식 JSON 열기·저장을 이용할 수 있다.

웹 새로고침과 네이티브 재실행, 첫 미리보기, 개인 기본값 복원, 이전 문서 열기를 확인한다. 잘못된 값이나 저장 공간 오류가 발생하면 사용자에게 알리고 기존의 유효한 기본값을 보존한다. 읽을 수 없는 기본값이 있어도 쪽결 기본 양식으로 편집기를 열 수 있어야 한다.

서로 다른 모델 ID·주소의 로컬 시험 서버로 실제 수신한 요청을 대조한다. LM Studio를 포함한 여섯 공급자 선택에서 선택한 모델로 양식 제안이 전달되는지, 설정 취소·모델 변경·오래된 응답·키 재입력·서버 중단·빈 설정에서 의도한 동작을 하는지 확인한다. 기존 고정 모델 평가 경로와 내장 모델도 별도로 검증한다.
