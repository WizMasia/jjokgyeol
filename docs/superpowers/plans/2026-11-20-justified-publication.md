# 출판 양끝맞춤 구현과 인수

[요구사항과 줄 맞춤 기준](../specs/2026-11-20-justified-publication.md)을 따른다. 실제 PDF에서 마지막 문자의 진행 폭까지 측정한다.

- [ ] 새 출판 기본 양식, 편집기 열기·저장·다운로드, 저장된 고정 및 balanced 양식의 지면을 검사한다.
- [ ] 어절 경계에서 문단 줄바꿈을 선택하고 실제 가변 자간과 공백을 조판한다. 문단·목록의 마지막 줄, 긴 어절, 제한된 폭과 입력 크기를 검증한다.
- [ ] 같은 원고의 변경 전후 PDF와 수치를 대조한다. 사용자에게 전달한 익명 표본을 교체하고 새 편집자 원고와 양식을 준비한다.
- [ ] 실모델과 규칙의 후보·재생 결과, 전체 테스트, 배포한 편집기를 확인하고 비공개 GitHub에 반영한다.
