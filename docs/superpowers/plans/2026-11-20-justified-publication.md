# 출판 양끝맞춤 구현과 인수

[요구사항과 줄 맞춤 기준](../specs/2026-11-20-justified-publication.md)을 따른다. 실제 PDF에서 마지막 문자의 진행 폭까지 측정한다.

- [x] 새 출판 기본 양식, 편집기 열기·저장·다운로드, 저장된 고정 및 balanced 양식의 지면을 검사한다.
- [x] 어절 경계에서 문단 줄바꿈을 선택하고 실제 가변 자간과 공백을 조판한다. 문단·목록의 마지막 줄, 긴 어절, 제한된 폭과 입력 크기를 검증한다.
- [x] 같은 원고의 변경 전후 PDF와 수치를 대조한다. 사용자에게 전달한 익명 표본을 교체하고 새 편집자 원고와 양식을 준비한다.
- [x] 실모델과 규칙의 후보·재생 결과, 전체 테스트, 배포한 편집기를 확인하고 비공개 GitHub에 반영한다.

## 인쇄 지면 검증

측정값은 PDF 글자 시작 좌표에 마지막 글자의 진행 폭을 더해 얻었다. 한 줄짜리 문단과 문단의 마지막 줄은 자연스러운 길이로 두고, 나머지 줄은 본문 오른쪽 기준선과의 거리를 측정했다.

| 출력 | 기준선 오차 0.05 PDF pt 이내 | 최대 오차 |
| --- | --- | --- |
| 종전 판독 묶음 12장 | 0 / 99줄 | 52.71 PDF pt |
| 새 판독 묶음 12장 | 90 / 90줄 | 0.015 PDF pt 미만 |
| 전후 비교 원고, 종전 양식 | 0 / 11줄 | 45.14 PDF pt 미만 |
| 전후 비교 원고, 새 양식 | 10 / 10줄 | 0.01 PDF pt 미만 |

새 판독 묶음에서 원문과 인쇄 문자, 어절 경계, 마지막 줄의 기본 간격을 모두 확인했다. 같은 원고를 편집기에서 내려받고 양식을 저장·재개방해도 글자와 위치가 같았다. 일반 보고서는 이어지는 목록 줄의 들여쓰기와 오른쪽 끝을 검사했다. [같은 원고의 전후 비교](../../../proofs/justified-publication/comparison.png) · [일반 보고서 PDF](../../../proofs/general-report/general-report.pdf)

별도 원고 2편을 규칙과 실모델로 조판한 PDF 4개에서 여백·간격 위반과 선택한 줄 끝의 불일치가 각각 0건이었다. 후보가 선택한 줄별 간격과 글꼴의 영문 커닝을 포함한 글자 위치도 대조했다. 익명 표본 12장의 선호표와 편집자 기준 지면은 판독 대기 상태다.

네트워크를 끈 테스트 이미지에서 62개 모듈의 검사 1,011건이 통과했다. 환경에 의존하는 검사 58건은 해당 실행에서 건너뛰었다. 호스트에서는 편집기·실모델 등을 연결한 검사 30건과 지면·양식 호환성 검사 28건이 각각 통과했다. 실행 중인 편집기의 앱 파일 51개가 저장소와 SHA-256까지 일치했다.
