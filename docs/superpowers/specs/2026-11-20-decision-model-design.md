# T13 실측 후보의 로컬 모델 선택

미리보기와 다운로드의 기본값은 T11 규칙이다. 운영자가 같은 로컬 LM Studio를 연결하고 요청자가 model을 지정한 경우에만 모델을 쓴다. 웹·로컬 이미지에 같은 실파일 SHA-256과 응답 런타임 이름·버전을 넣는다. 운영자 모델 폴더의 읽기 전용 마운트, 현재 로드한 variant, 실제 추론 응답의 모델·런타임을 확인한다. 별도 엔진을 배포하는 방안보다 현재의 두 배포판에서 같은 가중치와 실행기를 검증하기 쉽다.

작업자는 원본과 양식을 그대로 두고 규칙 PDF와 실측 행을 먼저 만든다. 후보는 현재 양식의 자간·공백 범위와 줄 끝·폭을 검사한다. 추론에는 순번과 수치·문장부호 분류만 쓴다. 유효한 선택만 T11 ID로 되돌려 새 작업 폴더에서 재생한다. 작업 전체가 하나의 추론·재생 기한을 공유한다. 만료되면 이미 만든 규칙 PDF를 돌려준다. 재생 결과도 검사하고 모델 불가·오답·불일치 시 규칙을 사용한다.

T14는 같은 원고와 양식으로 /api/render에 rule 및 model을 지정하고 응답의 실제 선택 경로를 기록한다. 별도의 창작 개발 표본에서 PDF의 최종 문자 좌표와 각주를 판독한다. 사람 평가와 기본값 변경은 T14 이후에 결정한다.
