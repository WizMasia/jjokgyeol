# 정수 조판과 문단 폭 구현 계획

**목표** 웹 편집기의 퍼센트·mm·pt 입력을 정수 양식으로 변환하고, 같은 허용 폭으로 한글 혼합 문단을 조판한다. [제품 스펙](../../../SPEC.md) · [정수 연산 설계](../specs/2026-11-19-fixed-point-layout-design.md)

**구성** FastAPI의 기존 요청 경로와 LuaLaTeX 엔진을 사용한다. 내부 필드는 `page_sp`, `margins_sp`, `body_sp`, `leading_sp`, `first_indent_sp`, `rest_indent_sp`, `ko_tracking_per_10000`, `space_per_10000`이다. 길이는 1pt당 65536sp이며 비율의 분모는 10000이다. 외부 양식의 `first_indent_mm`, `rest_indent_mm`는 기본 0이다.

- [x] 양식·API. `app/style.py`, `app/jobs.py`, `tests/test_input.py`에서 기존 JSON 숫자와 편집기의 십진 문자열, 정수 양식 왕복, 음수 절반과 원래 범위 검사, 두 줄 폭이 모두 양수인 조건을 먼저 테스트한다. 백엔드는 원래 십진 표기를 읽고 정수만 직렬화한다.
- [x] 조판. `app/tex/layout.lua`, 필요 시 Lua 모듈, `tests/test_typeset.py`에 100개 간격의 합, 한글·영문의 경계, 고정 후보 및 공백 한계를 검증한다. 정수 누적과 줄별 정산에 같은 단위를 쓰고 TeX에 간격을 한 번 적용한다.
- [x] 줄 경계. 실제 줄 시작과 폭에 첫 줄·이후 줄 양식을 반영한다. 보통 한글 어절과 한 줄보다 긴 어절, 혼합 원고와 각주에서 실제 PDF의 줄 끝과 시작 위치를 검사한다.
- [x] 편집기. `app/static/`, `tests/test_editor.py`에서 십진수 원문 전달, 적용된 비율 표시와 들여쓰기 입력을 검증한다. 이전 버전 응답이 편집 중 값을 덮지 않게 한다.
- [x] 양식 파일. `POST /api/style/export`로 편집값을 정수 JSON으로 저장하고 `POST /api/style/open`으로 검증한 뒤 편집 단위로 되돌린다. `tests/test_style_file.py`에서 기본 A5, 소수 크기와 들여쓰기, 손상된 파일 이후 복구를 확인한다.
- [x] 통합. 기존 PDF 및 브라우저 회귀를 실행하고 오프라인 Docker 테스트와 독립 배포 비교를 반복한다. 실제 편집기로 PDF를 내려받아 미리보기 해시와 문자 좌표를 확인한다.

## 최종 검증 · 2026-11-19

| 항목 | 측정 결과 |
|---|---|
| 정수 자간 | 11pt 한글 101글자 사이 100개 간격에 −7%를 적용한 조판 노드의 합은 −5,046,272sp였다. 실행 중인 서비스의 0%와 −7% PDF에서 첫 글자와 마지막 글자의 시작점 사이 거리는 76.7123 PDF pt 줄었다. |
| 반올림과 줄 경계 | −7.245%는 −7.25%로, 70.005%는 70.01%로 적용됐다. 정수 양식을 저장·재개방해 값이 같았고, 글자 폭이 1sp만큼 맞거나 부족한 경우를 구분했다. |
| 문단 폭과 조판 | A5·14pt 예시에서 첫 줄 시작점은 51.024 PDF pt, 이어지는 줄은 68.032 PDF pt였다. 6mm 내어쓰기가 둘째 쪽에서도 유지됐다. 긴 한글 어절·영단어·URL, 결합 문자, 각주 이동과 폭이 부족한 경우의 복구를 회귀 검사했다. |
| 실제 브라우저 | 원고와 양식을 각각 열어 생성한 2쪽 PDF는 120,489바이트였다. 미리보기와 내려받은 파일의 SHA-256은 모두 `9daa68a64bc51a40b3ab9472d57748708c9f4e6ef6c714897bc0c7582addbadc`였다. 양식 저장 중 편집, 원고와 양식의 동시 열기, 손상 파일 이후 재개방도 검증했다. |
| 배포 | Linux ARM64 이미지 `jjokgyeol:local`의 digest는 `sha256:60b2ba7d074f1379d715618dc7d9dd8a0a428074b0092242e41ae07172d9be36`이다. 같은 코드의 테스트 이미지에서 네트워크를 끄고 실행한 결과 151건 통과. Docker 호스트가 필요한 나머지 1건은 이 배포 이미지의 독립 컨테이너 두 개로 줄 끝·쪽·글꼴을 대조해 통과했다. |
