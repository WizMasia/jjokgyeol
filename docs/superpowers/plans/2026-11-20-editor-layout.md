# 편집기 입력창·메뉴 정렬 계획

원고와 교정지를 나란히 보는 편집 흐름을 유지한다. 출판 양식의 기본 네 항목은 라벨과 값을 같은 기준선에 놓고 네이티브·웹에서 사용할 수 있는 메뉴를 묶는다. 세부 양식에서는 라벨과 입력칸을 일정한 열에 배치하고 내용은 위에서부터 채운다. 짧게 끝나는 그룹의 항목 사이에 빈 공간을 늘리지 않는다. 좁은 창에서 문구와 단위는 해당 입력과 함께 다음 행으로 이동한다. 기존 색·글꼴·읽기 순서와 파일·편집 계약을 사용한다.

- [ ] 실제 편집기에서 화면 폭과 필드의 위치를 읽는 회귀 시험으로 행 정렬과 가로 넘침을 확인한다.
- [ ] 공유 HTML·CSS에서 원고 및 교정지 도구, 기본 양식, 선택 메뉴, 여백·들여쓰기·줄 번호, 단계별 목록을 정렬한다. 숨겨진 설정과 네이티브 전용 가시성을 유지한다.
- [ ] 넓은 창과 좁은 창에서 실제 입력과 토글을 시험하고 전후 스크린샷을 남긴다. 기존 웹 비교판을 별도로 유지하고 편집 화면을 포함한 Mac 앱을 다시 빌드한다.
