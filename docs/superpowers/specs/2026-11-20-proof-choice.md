# 모델·규칙 조판 선택

사용자가 모델 조판을 우선하되 두 지면을 직접 골라 쓰도록 정했다. 한 번의 갱신에서 같은 원고와 양식의 규칙 PDF를 만든 뒤 동일한 후보에서 모델 PDF를 만든다. 일반 편집기는 기존 렌더 경로에 비교 응답을 요청하고, 전환할 때는 보관한 PDF를 사용한다. 새 세션의 기본은 모델, 명시적으로 고른 방식은 현재 편집 세션에서 다음 갱신에도 우선한다. 모델이 일부 문단에만 적용됐거나 규칙으로 복귀한 경우 화면에 실제 상태를 표시한다. 다운로드는 선택한 지면과 같은 PDF다. 참고 양식 시험 조판을 적용할 때도 선택과 출력이 일치해야 한다. 저장된 원고와 양식에는 화면 선택을 넣지 않는다.

비교 요청은 POST /api/render에 기존 JSON과 Accept: multipart/form-data 헤더를 보낸다. 모델이 적용되면 rule, model 두 파일 부분을 전달하고 X-Jjokgyeol-Decision은 model 또는 mixed다. 규칙 결과만 있으면 application/pdf와 상태 rule을 전달한다. 단일 PDF API와 기존 평가 입력은 유지한다. 비공개 사람 판독은 별도로 진행한다.
