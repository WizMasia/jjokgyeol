# 계층 목록과 여백 줄 번호

출판 양식에서 계층 번호형을 선택하면 중첩 마크다운 목록의 실제 순번을 점으로 잇고 끝에 점을 붙인다. 같은 부모 아래에서 증가하고 새 부모의 첫 하위 항목은 1로 시작한다. 숫자로 시작한 목록은 명시한 시작값을 따른다. 긴 항목의 다음 줄, 여러 자리 번호와 깊은 목록도 기존 표지 폭 측정과 내어쓰기를 쓴다.

줄 번호는 일반 출판 양식에서 끔·왼쪽·오른쪽을 고른다. 제목·본문·목록의 최종 인쇄 줄마다 1부터 연속해서 물리적 왼쪽 또는 오른쪽 여백에 찍는다. 쪽이 바뀌어도 이어지고 각주·미주·머리글·바닥글과 빈 공간은 제외한다. 숫자에 필요한 여백이 부족하면 해당 양식 오류를 표시한다. 줄 번호가 본문 폭이나 페이지 배치를 바꾸면 안 된다. 두 옵션은 각각 저장하고 열 수 있으며 마크다운 원문을 보존한다.

원고에 완성된 표지를 직접 입력하거나 편집기에서 원고 줄을 세는 방식도 고려했다. 항목을 이동하거나 지면이 재배치될 때 번호가 맞도록 조판 시점에 결정한다. 이전 양식에는 줄 번호 필드를 추가하지 않는다.

홀짝 따로 지정은 최종 PDF의 물리적인 면에 적용한다. 홀수와 짝수에 왼쪽·오른쪽·끔을 각각 정하고, 숨김은 줄 번호의 표시만 바꾼다. 공통 위치를 지정한 기존 파일은 원래 문자열을 유지한다. 면별 선택은 `line_numbers`의 `odd`와 `even`에 함께 저장한다.
