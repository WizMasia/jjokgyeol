# 혼합 문단 통합 교정

T9 풀이와 T11 문단 후보를 함께 쓰는 원고에서 독립 검토가 재현한 세 지면을 교정한다.

- T13 선택 기록의 `end_glyph`는 공백을 뺀 본문 글리프의 누계다. U+3000의 인쇄 폭과 다음 한글의 시작 좌표를 보존한다.
- 좁은 첫 줄을 비워 풀이 묶음을 다음 줄에 놓을 때, 빈 줄과 첫 인쇄 줄을 같은 쪽에 둔다. 제목 뒤에서도 같은 규칙을 쓴다.
- 실측 문단이 풀이 처리로 넘어가도 연속 공백 주변의 여는 따옴표와 닫는 따옴표에 기존 금칙을 적용한다. 풀이 묶음과 저자가 입력한 공백 폭을 유지한다.
