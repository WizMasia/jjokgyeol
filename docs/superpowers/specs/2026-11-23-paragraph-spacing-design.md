# 문단 위·아래 여백과 디시전 모델

## 편집 경험

보고서에서 제목 앞을 넉넉히 띄우고, 날짜와 작성자 아래만 따로 띄울 수 있게 한다. 웹과 Mac에서 같은 원고와 양식으로 같은 규칙 PDF를 만든다. 줄 간격은 문단 안에서, 이 설정은 문단과 다음 문단 사이에서 적용한다.

단계 전체에 공통값만 주는 방법은 양식을 간단히 관리할 수 있고, AI 제안을 매번 확인하는 방법은 조판 때마다 편집자의 선택이 필요하다. 기존에 위임받은 선택에 따라 양식 기본값, 개별 예외, 자동 조판을 함께 쓰는 방식을 제안한다.

- 단계별 서식에서 0단계 본문, 제목 1~6, 기존 목록 각 단계에 ‘문단 위’와 ‘문단 아래’를 둔다. 각각 ‘기본’, ‘AI 자동’, ‘직접 입력’을 선택한다. 기존 파일과 새 문서의 초기값은 ‘기본’이다.
- 원고에서 본문이나 제목 한 곳에 커서를 두고 기존 문단 편집 기능에서 위·아래를 각각 ‘양식 따르기’, ‘AI 자동’, ‘직접 입력’으로 바꾼다. 목록은 기존 단계별 목록 양식에서 조정하고, 여러 줄로 감긴 한 목록 항목은 한 문단으로 취급한다. 한 항목 안에서 빈 줄로 나눈 실제 문단에는 각각 그 목록 단계의 값을 적용한다. 하위 목록은 자기 단계의 값, 재개한 상위 문단은 원래 단계의 값을 쓴다. 표 안, 코드 안, 각주 안에는 본문 설정을 상속시키지 않는다.
- 수치 단위는 pt이다. 예컨대 제목 위 12pt, 아래 4pt를 입력하거나, 위는 자동으로 두고 아래만 6pt로 고정한다. 입력 범위는 0~72pt를 제안한다. 0pt는 문단 경계에 추가하는 수직 간격을 0으로 지정한다. 글줄의 높이와 깊이, 기본 줄 간격, 제목 틀의 안쪽 여백은 유지한다. 화면의 적용 수치도 이 추가 간격을 뜻한다. 입력란의 미완성 문자열은 저장이나 적용 전에 검증한다. 양식 따르기를 선택하면 그 방향의 개별 지정만 해제한다.
- ‘AI 자동’은 사용자가 ‘모델 우선’으로 교정쇄를 만들 때 자동 적용한다. 규칙 조판, 모델 미연결, 시간 초과에도 규칙값으로 PDF를 만든다. 미리보기 상태와 선택한 문단에서 최근 교정쇄의 실제 경계 간격과 결정 출처(직접·양식·AI·규칙 대체)를 확인할 수 있게 한다. 원고 또는 양식이 바뀌면 이전 결과임을 표시한다. 사용자가 원하는 적용값을 직접 입력해 고정할 수 있다.

## 두 문단 사이의 한 간격

각 방향은 개별 지정 후 양식 상속 순서로 해결한다. 앞 문단의 아래와 뒤 문단의 위가 같은 지면에서 만나면 하나의 간격만 둔다. 한쪽이라도 수치가 지정되면 그 경계에 AI를 호출하지 않는다. 수치가 하나면 그 값, 둘이면 큰 값을 쓴다. 예컨대 앞 문단 아래 6pt와 다음 제목 위 12pt는 합쳐서 12pt이다. 한쪽의 명시적 0pt와 상대의 기본 또는 자동은 0pt이다. 양쪽 모두 기본일 때는 현재 조판 엔진의 문단 간격을 그대로 사용한다. 기본 본문 간격은 현재 4pt이다.

새 쪽 맨 위와 맨 아래에는 경계 여백을 출력하지 않는다. 긴 문단이 쪽을 넘어 이어질 때에도 내부에 여백을 삽입하지 않는다. 제목 틀은 바깥 경계에 여백을 한 번 붙이고 제목과 다음 내용의 묶음을 보존한다. 표·목록이 본문이나 제목 옆에 있을 때에는 해당 본문·제목의 지정값이 바깥 경계에 한 번만 적용되어야 한다. 표의 열 제목 반복, 각주, 쪽의 본문 영역은 기존 정책을 따른다.

## 규칙 및 모델 경로

출판 설정에서 범위, 기존 간격, 자동 후보 정책을 공유한다. 규칙 모드의 자동값은 같은 경계의 기존 간격을 기준으로 정한다. 모델 우선에서는 현재 본문 크기, 단계, 인접 블록의 종류, 측정한 쪽의 남은 공간과 줄 수 등 수치와 구조 정보로 간격 후보를 구성한다. 첫 버전의 자동 후보는 기본, 본문 크기의 절반, 본문 크기 한 배로 하며, 범위 안에서 중복을 없앤다. 직접 입력 범위는 자동 후보보다 넓다.

기존 줄바꿈 모델과 인증·세션·기한을 공유하되 여백 선택 요청은 구분한다. 원문, 제목 문자열, 글꼴 파일은 여백 판단에 전송하지 않는다. 모델은 제공한 후보 ID를 반환하며, 검증된 후보만 재조판에 사용한다. 내장 모델은 로컬 인터페이스에 여백 선택 기능이 있을 때 사용하고, 기존 줄바꿈 전용 모델은 해당 경계에서 규칙으로 대체한다. 외부 모델이 유효한 여백 후보를 선택한 경우에도 같은 검사를 거친다. 한쪽의 실패가 다른 쪽에서 성공한 줄바꿈 또는 직접 지정한 값까지 취소하지 않도록 한다. 기존 제한 시간 안에 규칙 교정쇄를 먼저 확보하고, 여백 판단 비용은 문서 길이에 비례해 무제한 호출되지 않도록 제한한다.

새 PDF에서 경계가 쪽을 넘어가면 그 간격은 소멸한다. 넘치는 지면, 빈 쪽, 제목과 본문의 잘못된 분리 같은 결함을 일으킨 자동 결과는 마지막으로 검증된 PDF로 되돌린다. 명시적 수치와 규칙 여백으로 조판한 PDF를 먼저 확보하고, 유효한 모델 줄바꿈이 있으면 그 줄바꿈과 규칙 여백의 PDF를 다음 기준으로 보관한다. 여백 재조판이 실패하거나 기한을 넘기면 실패한 여백 묶음을 버리고 이 기준 PDF와 그 결정 내역을 함께 반환한다. 채택한 실제 조판 결과로 미리보기와 상태를 함께 갱신한다. 자동 모드의 선택만 양식에 저장한다. 교정쇄 생성 자체는 원고를 편집한 것으로 표시하지 않는다.

## 저장과 검증

기존 Style의 역할별·목록별 필드와 정수 sp 저장을 재사용한다. 단계값은 양식 JSON 및 .jjok에, 개별 지정은 원고의 기존 쪽결 주석 방식을 확장해 .md와 .jjok에 왕복 보존한다. 정렬 주석·조 제목 번호·실행 취소와 함께 동작해야 한다. 값 생략, 자동, 명시적 0, 소수값은 왕복 후에도 구별한다. 편집 도중 늦게 도착한 미리보기는 다른 문단에 수치를 표시하거나 원고를 수정할 수 없다. 교정 PDF를 포함해 저장한 .jjok은 마지막 교정쇄를 다시 볼 수 있고, 새로 조판할 때에는 현재 연결을 사용한다. 이번 버전에서 개별 경계의 결정 내역은 조판 세션에만 둔다. 저장된 PDF를 다시 열면 원고·양식의 지정값을 표시하고, 실제 적용값과 출처는 ‘미리보기 갱신 후 확인’으로 표시한다.

회귀 검사는 기본값만 있을 때 변경 전 PDF와 같은 글자 위치·쪽 수, 줄 간격과 단락 간격의 독립성, 양쪽 수치가 만나는 경계, 부분 고정, 쪽 경계와 긴 문단, 틀 제목·목록·표·각주를 포함한다. 규칙·고정된 시험 모델에서 실제 PDF 좌표로 검증한다. 모형 제공자의 자동 후보 선택·거절·시간 초과, 오프라인 대체, 웹·Mac 간 원고와 양식의 왕복, 자동값 조회 후 직접 고정도 확인한다. 각 모델 응답을 어떤 단위로 묶을지와 화면 컨트롤의 정확한 배치는 구현 단계에서 정한다.
