# 개인 기본값과 모델 선택 구현 계획

승인된 개인 기본값 설계에 따라 웹과 네이티브에서 양식과 비밀이 없는 모델 설정을 기억하고, 모든 외부 모델 선택에서 직접 입력과 명시적 목록 조회를 지원한다.

- [x] 개인 기본값. 편집기의 양식 내보내기·열기와 설정창을 재사용한다. 브라우저 프로필과 네이티브 WebView의 영구 저장소에서 재시작, 복원, 비밀 제외, 오래된 요청 및 저장 실패를 시험한다.
- [x] 모델 통신. 공급자 카탈로그에 Ollama 다음으로 LM Studio를 추가한다. 공통 연결 검증·인증·기한을 통해 목록 GET과 양식 제안 JSON을 제공한다. 공급자별 로컬 서버에서 경로, 페이징, 인증, 응답 형식, 실패를 검사한다.
- [x] 양식 제안. 편집기에서 적용한 연결을 분리 작업자의 표준 입력으로 전달한다. 기본 Gemma 접속을 제거하고 설정 안내와 목적지를 표시한다. 서버 원문이나 키를 임시 파일에 기록하지 않는다.
- [x] 목록 조회. 웹 POST /api/decision/models 및 네이티브 list_decision_models 명령이 공통 목록 함수를 호출해 {models: [ID]}를 반환한다. 실제 편집기의 자유 입력·목록 선택·빈 목록·지연 응답을 시험한다.
- [x] 통합. 기존 고정 모델 평가, 규칙·내장 조판, 기존 문서 열기와 두 편집기의 설정 취소를 회귀 검사한다. 브랜치 병합·푸시 뒤 세 설치 파일을 검증해 다음 시험판을 게시한다.

## v0.1.1-preview.4 검증 기록

2026-11-24에 릴리즈 커밋 `febc93d`를 main과 네이티브 브랜치에 통합했다. Docker 회귀 검사 1,988건 중 1,925건이 통과했고 63건은 조건부로 건너뛰었다. 첫 실행에서 제한 시간을 넘긴 9건은 같은 이미지에서 개별 또는 순차 실행해 통과를 확인했다. 고정 모델의 기존 평가 자료 재검사와 실제 LM Studio의 본문·바닥글 제안을 PDF에 반영하는 검사도 별도로 통과했다.

로컬 웹판에서 브라우저를 재시작한 뒤 개인 본문 크기, 선택한 LM Studio 연결, 수동 모델 목록이 복원됐다. 웹판과 Mac 설치본 양쪽에서 실제 서버의 모델 ID 9개를 읽었다. 웹과 네이티브의 문서 왕복 검사 4건을 통과했고 Mac에 동봉한 조판기가 만든 10쪽 보고서는 기존 교정 PDF와 글자·좌표가 일치했다.

Windows와 Ubuntu 설치본은 GitHub Actions에서 빌드했다. Mac 실행기 배정이 두 차례 실패해 같은 커밋의 공식 스크립트와 CI가 내보낸 TeX 자료로 Apple Silicon Mac에서 DMG를 빌드하고 설치 검사를 수행했다. 세 설치 파일과 해시 목록을 시험판으로 공개했다.
