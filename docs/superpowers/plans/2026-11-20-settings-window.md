# 출판 설정창

원고와 지면이 있는 기본 창의 도구 막대에 설정 버튼을 둔다. 네이티브 앱은 독립 창 한 개를 열고 재호출 시 작성 중인 창으로 초점을 옮긴다. 웹에서는 같은 입력 UI를 모달 대화상자로 연다. 파일 형식과 기본값은 기존 Style 모듈을 따른다.

- [ ] 네이티브에서는 메인 창이 편집 양식의 스냅샷을 전달한다. 설정창은 조판·견본 원고를 시작하지 않는다. 적용은 검증한 양식을 메인 창에 전달하고, 취소는 메인 창에 쓰기 전에 닫는다. 원고 상태와 PDF는 설정창에 넘기지 않는다. 원래 창이 닫히면 설정창도 정리한다.
- [ ] 웹의 출판 양식, 양식 파일, AI·참고 문서·머리글 도구는 설정 안에서 계속 사용할 수 있다. 열기·닫기와 초점 복귀를 시험한다.
- [ ] 기존 양식의 mm·pt, 자간, 양면 여백, 저장과 열기를 정상 진입점에서 검사한다. 창 중복, 변경 적용, 취소, 저장하지 않은 원고 보존을 확인하고 Mac 앱에서 두 창과 PDF를 직접 확인한다.
