# T11 혼합 문단 후보와 재생

같은 혼합 원고를 좁은 판형과 넓은 판형에 조판한다. 앞줄에 영단어를 넣기 위해 공백을 얼마나 줄였는지, 뒷줄에 한 글자만 남았는지, 어느 후보를 출력했는지를 실제 지면과 대조할 수 있어야 한다.

## 채택한 방식

기존 조판기의 글꼴 선택과 shaping 이후, 같은 노드에서 문단 전체의 배치를 비교한다. 가능한 모든 줄 끝 조합을 열거하면 긴 원고에서 비용이 급증한다. 위임된 1안으로 기본 간격 우선·허용 하한까지 맞춤의 두 배치를 만들고, 각각 끝에서 한 어절을 다음 줄로 옮긴 배치까지 최대 네 개를 검토한다. 줄 수, 외톨이 마지막 글자, 간격 변화와 줄 끝 여백을 문단 단위로 비교한다. 동률은 생성 순서로 푼다.

- 첫 줄과 계속 줄의 실제 시작점·폭을 쓴다. 각 줄은 기본 자간과 글꼴 공백에서 시작해 필요한 만큼만 줄인다. 한글 자간 보정은 양식에 최종 범위가 있을 때만 적용한다. 줄을 채우기 위한 마지막 줄 확장은 하지 않는다.
- 일반 어절은 통째로 옮긴다. 빈 첫 줄 또는 다음 줄에도 들어가지 않는 긴 어절은 기존 `wordbreak`의 문자 묶음·금칙 경계에서 나눈다. T9의 풀이 표시도 이 경로를 공유한다. 원고, 각주 삽입 노드와 참조 번호를 보존한다.
- 본문 문단이 대상이다. 제목·주·목록의 조판, 명시적 TeX 강제 줄바꿈과 T3 교정용 지정 배치는 기존 경로를 사용한다. 제목과 다음 본문은 쪽 경계에서 실제 PDF로 확인한다.
- 원고와 양식은 T13이 수정할 수 없다. 조판할 때마다 현재 유효 후보를 다시 만들고 일치하는 ID만 적용한다. 모델 호출·학습은 T13의 책임이다.

## T13 계약

`app.typeset.typeset(doc, style, workdir, *, collect_candidates=False, paragraph_choices=None) -> bytes`. 수집 시 빈 작업 폴더에 UTF-8 `paragraph-candidates.jsonl`을 만든다. 줄마다 한 본문 문단의 `block`(조판 입력의 1기준 블록 번호), `candidates`, 규칙 ID `rule_id`, 실제 출력 ID `selected_id`가 있다. 후보의 `id`는 불투명 문자열이고 `lines`는 지면 순서다. 각 줄의 길이는 sp, 비율은 10000이 100%인 정수다.

줄 특징은 누적 끝 글리프 번호 `end_glyph`(공백·참조 상자 내부 제외), 첫·끝 유니코드 `first_char/last_char`, `start_sp/available_sp/remaining_sp`, 최종 `tracking_per_10000/space_per_10000`, 기본 대비 `tracking_delta/space_deviation`, 직전 줄 대비 `tracking_change/space_change`, 어절 내부 개행 여부 `split_word`다. 줄 끝 번호는 마크다운 오프셋과 구분한다.

소비자는 문단별 `choose(row["candidates"])`의 ID만 모아 새 작업 폴더에서 `paragraph_choices={block: id}`로 다시 조판한다. 입력·양식·블록·실측 배치를 ID에 결합한다. 누락·불일치 시 그 문단의 규칙 배치를 쓴다. 수집을 켜면 재생 결과도 같은 형식으로 대조할 수 있다.
