# 참고 문서에서 서식 가져오기

쪽결에서 열어 둔 마크다운 원고에 기존 보고서의 서식을 골라 적용한다. 사용자가 선택한 단위는 **참고 문서의 구간과 그 구간의 개별 속성**이다. 결과는 다시 편집할 수 있는 출판 양식과 현재 원고로 조판한 PDF다. [제품 스펙](../../../SPEC.md#참고-문서에서-서식-가져오기)

## 선택한 분석 방식

DOCX·HWPX는 파일에 저장된 값을 읽는다. 텍스트 PDF는 쪽 크기와 배치 정보를 읽고, 스캔과 이미지형 PDF 쪽은 비전 모델로 분석한다. 한 PDF 안에서도 쪽마다 분석 방식을 고른다.

| 모델 연결 방식 | 사용자가 선택할 때의 차이 |
|---|---|
| **운영자 연결 모델 · 선택** | 웹판과 로컬판이 같은 분석 인터페이스를 쓴다. 로컬 인수 시험은 설치된 LM Studio와 이미지 입력 모델을 사용한다. |
| 사용자 기기에서만 추론 | 웹 사용자도 자신의 기기에 모델을 준비해야 한다. |
| 외부 비전 서비스 우선 | 제공사 계정과 참고 지면 전송이 기본 사용 조건이 된다. |

연결 주소·모델 이름·필요한 인증은 서버 운영 설정에 둔다. 사용자가 분석을 시작할 때 스캔 지면을 처리할 모델을 표시한다. 모델에는 분석할 참고 지면과 서식 판독 요청을 전달한다. 출력 후보에는 지정된 서식 필드만 받아들이고 숫자·단위·범위를 확인한다. 모델 연결 실패는 해당 쪽에 표시해 다시 시도할 수 있게 하고, 이미 읽은 구조·텍스트 쪽의 후보는 검토할 수 있게 한다.

운영자 연결에는 이미지 입력을 지원하는 호환 Chat Completions 인터페이스를 사용한다. [LM Studio 문서](https://lmstudio.ai/docs/developer/openai-compat/chat-completions)

## 참고 파일 판독과 근거

- **DOCX·HWPX**에서 문서의 사용 순서대로 구역·문단·글자 속성 및 목록 정의를 따라간다. 기본값·상속 스타일·직접 지정 값의 적용 결과를 제시한다. 실제 쪽을 식별할 수 있는 경우 쪽과 블록을, 나머지는 구역·문단 번호와 원문 발췌를 근거로 표시한다. 논리적 구역을 물리적 쪽으로 오인하지 않도록 근거 단위를 표시한다.
- **PDF**는 쪽 크기와 글자 크기·위치·색 등 읽을 수 있는 값을 수집한다. 여백과 문단·목록 들여쓰기, 반복되는 머리글·바닥글의 역할은 해당 쪽의 배치를 근거로 제안한다. 참고 지면에서 반복되는 실제 쪽 번호를 고정 문자열로 복사하지 않는다.
- **스캔**은 지면 이미지에서 상대 위치·크기와 글자·목록의 역할을 추정한다. 사용자가 실물 판형이나 기준 길이를 입력하면 해당 이미지의 치수를 환산한다. 글꼴을 식별하기 어렵거나 설치되지 않았으면 대체 후보를 보여 주고 저자가 고른다. 내장 썸네일이나 이미지가 없는 구조 문서는 대표 문단의 서식 견본과 출처를 보여 준다.
- 같은 속성이라도 구간마다 값이 다를 수 있다. 후보에는 **속성, 값·단위, 적용 요소, 읽음/추정/확인 필요, 근거 위치**를 붙인다. 페이지별 후보 또는 문단 단위 근거를 재사용해 사용자가 경계를 수정하면 선택 범위에 속하는 자료만으로 후보를 다시 구성한다.

## 검토와 적용

1. 편집기에서 **참고 문서 서식 가져오기**로 파일을 연다. 표지·목차·본문 등 제안된 참고 구간과 근거를 살펴보고 범위를 고친다. 참고 파일의 본문과 이미지는 현재 원고로 들어가지 않는다.
2. 속성마다 현재 값과 제안 값을 대조하고 필요한 것만 고르거나 직접 수정한다. 적용 대상을 문서 전체, 원고 제목으로 구분한 구간, 그 안의 제목·본문·목록 중에서 선택한다. 판형처럼 쪽 전체에 필요한 속성은 가능한 범위를 표시한다. 아직 출력할 수 없는 속성은 근거와 지원 상태만 표시한다.
3. 양식은 기존 전역 값과 선택적인 구간별 변경 값으로 구성한다. 구간은 마크다운 제목의 경로로 식별한다. 앞쪽 글이 늘어나도 같은 구간을 따른다. 제목이 사라지거나 중복되어 하나로 식별할 수 없으면 적용 대상을 다시 선택한다. 같은 대상·속성에 값이 겹치면 사용자가 고른 값 하나를 사용한다. 구간에 본문 크기만 지정하면 그 안의 제목·목록은 각각의 기존 크기를 따른다.
4. **시험 조판**은 현재 원고와 임시 양식을 기존 PDF 엔진으로 조판한다. **적용**하면 검증한 후보 묶음을 한 번에 확정한다. **취소**·검증 실패·분석 실패 때는 확정 양식과 PDF를 보존한다. 검토 중 원고나 양식이 바뀌면 새 상태를 기준으로 다시 시험한다. 기존 JSON을 계속 열 수 있고 새 양식에는 선택한 구간·속성과 정수 길이·비율을 저장한다.

| 속성 | 이번 구현의 적용 대상 |
|---|---|
| 판형·사방 여백 | 문서 전체 |
| 글자 크기·지원 글꼴·색상·행간 | 전체 또는 선택한 제목 구간의 제목·본문·목록. 표제 하나만 골라 24pt로 출력할 수 있다. |
| 첫 줄·이후 줄 들여쓰기, 단계별 표지·들여쓰기와 간격 | 선택한 문단 또는 목록 역할. 선택한 제목 구간의 동일 역할에만 적용할 수 있다. |
| 머리글·바닥글 | 후보의 근거와 지원 상태 표시. 실제 출력은 머리글·바닥글 조판 과제에서 연결한다. |

구간 연결에는 같은 부모 아래에서 고유한 원고 제목 경로를 사용한다. 중복이면 해당 연결을 미적용으로 표시하고 다른 대상 선택 또는 원고 제목 수정을 허용한다. 양식 JSON에는 참고 파일의 이미지·문구·모델 응답을 넣지 않는다.

## 인수 기준

| 상황 | 실제 편집기와 PDF에서 대조할 결과 |
|---|---|
| 서로 다른 서식이 있는 DOCX와 HWPX | 직접 지정한 값이 상속값보다 우선한다. 본문 11pt 후보를 14pt로 고치면 선택한 대상의 본문만 바뀐다. 표지 제목과 목록 글리프 크기·좌표는 기준과 대조한다. |
| 텍스트 PDF, 스캔 이미지, 두 종류가 섞인 PDF | 쪽별 판독 방법·근거가 보인다. 실제 LM Studio 이미지 분석에서 후보를 받는다. 판형을 모르는 스캔에서는 상대값을 유지하고 판형 지정 후 환산을 확인한다. |
| 표지·목차·본문 구간을 수정하고 본문 목록 내어쓰기만 선택 | 수정한 범위에서 가져온 목록 값이 해당 원고 목록에만 반영된다. 내용을 앞에 추가해도 같은 목록에 적용된다. 다른 원고에서 대상을 찾지 못하면 다시 연결할 수 있다. |
| 시험 조판 후 적용·취소·실패, 저장·다시 열기 | 취소와 오류의 경우 기존 원고·양식·확정 PDF가 보존된다. 적용 후 같은 원고·양식의 미리보기와 다운로드는 같은 PDF이며, 양식 재개방 후에도 글자 크기·줄바꿈이 재현된다. |

분석기는 파일 크기·압축 해제량·쪽수·이미지 크기·처리 시간을 운영 설정 범위에서 처리한다. 인수 검증에는 직접 만든 원고와 참고 파일을 사용한다. 공개 배포 환경의 모델·인증 선택은 운영자가 맡는다.
