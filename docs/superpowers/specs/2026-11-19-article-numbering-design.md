# 조 제목 자동 번호

기존 조 제목을 인식한다. 가지조의 기준 번호는 기본적으로 기준 조를 따르고, `의2`·`의5` 같은 뒷번호는 유지한다. 사용자는 제목별로 번호를 고정할 수 있다.

원고에 이미 있는 조 제목을 그대로 편집하고, 미리보기를 갱신할 때마다 현재 순서에 맞는 번호를 읽을 수 있게 한다. 번호 표현식과 자동 번호 사용 여부는 출판 양식에 저장한다.

## 원고 표기 선택

| 검토한 방식 | 편집할 때 달라지는 점 |
|---|---|
| **기존 조 번호 인식 · 사용자 선택** | `# 제7조 목적`을 그대로 사용한다. 제목 단계와 무관하게 표기가 일치하는 제목만 센다. |
| 별도 표식 | `## [조] 목적`으로 조 제목을 명시할 수 있으나 기존 원고를 고쳐야 한다. |
| 제목 단계 지정 | 같은 단계의 모든 제목을 센다. 문서 제목이나 부칙을 그 단계에 함께 쓰기 어렵다. |

## 출력 규칙

- 편집기에 **조 제목 자동 번호**와 **조 번호 표현식**을 둔다. 기존 양식 파일에서 이 설정을 생략하면 기존 출력을 재현한다. 자동 번호를 켜면 기본 표현식은 `제{숫자}조`다. 목록과 같은 표현식 처리기와 검증을 사용하고 기본값은 출판 설정 한 곳에서 읽는다.
- 목록 바깥 마크다운 제목에서 `제7조`, `제7조의2`처럼 시작하고 곧바로 제목 끝, 공백 또는 여는 괄호가 오는 표기를 인식한다. 조판할 때 번호 부분만 바꾸고 괄호, 간격, 뒤따르는 제목과 강조를 보존한다. 일반 제목과 본문 속 인용은 원문대로 출력한다.
- 매 조판마다 첫 일반 조부터 순서대로 센다. 가지조는 일반 조의 순번을 소비하지 않는다. 가지조는 원고에서 같은 기준 번호를 가진 일반 조의 출력 번호에 원래 뒷번호를 붙인다. 기준 조가 하나라면 가지조보다 뒤에 있어도 찾는다. 여러 후보 중에서는 앞에서 가장 가까운 같은 번호를 사용한다. 후보를 식별할 수 없는 발췌는 입력 번호를 보존한다.
- 고정한 일반 조는 원고의 기준 번호를 사용하고 다음 일반 조는 그 다음 수부터 이어간다. 고정한 가지조는 원고의 기준 번호와 뒷번호 모두 유지한다. 번호 고정은 원고의 해당 제목에 저장하며 이동·저장·다시 열기 후에도 유지한다. 자동 번호와 번호 고정은 원고의 본문 인용에 영향을 주지 않는다.
- 일반 조·가지조·고정 조 각각의 첫 최상위 목록은 1부터 센다. 법령형에서는 첫 항이 ①이고 다음 항이 ②다. 첫 항에 마크다운 순번을 `7.`로 썼더라도 새 조에서는 ①이다. 하위 목록은 기존 단계별 양식을 따르고 쪽을 넘기는 도중에는 순번을 이어간다.

## 인수 검증

1. 브라우저에서 `제8조(목적)`, `제2조 시행`으로 시작한다. 미리보기에는 제1조(목적)·제2조 시행이 보이고 두 조의 첫 항은 모두 ①여야 한다.
2. 중간에 `제8조 정의`를 삽입한다. 목적·정의·시행이 각각 1·2·3인지 확인한다. 이어서 시행 조 전체를 맨 앞으로 옮기고, 시행·목적·정의가 각각 1·2·3인지 확인한다. 제목별 첫 항의 문구와 ①를 함께 대조해 항이 올바른 조에 딸려 있는지도 검사한다.
3. 각 단계에서 실제 미리보기 PDF와 다운로드 파일의 바이트를 대조하고, 그 PDF에서 제목과 항 번호를 추출한다. 결과 PDF와 해당 마크다운 원고는 함께 열 수 있게 제공한다.
4. 일반 조 삽입과 묶음 이동 전후에 가지조의 `의2`·`의5`를 비교한다. 가지조만 삽입해도 다음 일반 조 번호가 유지되고 가지조의 첫 항도 ①인지 검사한다. 고정한 일반 조와 가지조, 기준 조가 없는 발췌도 대조한다.
5. 사용자 표현식, 원고와 양식 저장·다시 열기, 자동 번호를 끈 원고, 일반 제목·본문 인용도 검사한다. 잘못된 표현식은 해당 입력란에 오류를 표시하고 직전 미리보기를 보존한다.
