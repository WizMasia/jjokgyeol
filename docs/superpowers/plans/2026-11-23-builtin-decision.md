# 내장 디시전 모델 연결

승인된 디시전 제공자 설계의 로컬 함수 경로를 구현한다. 모델 학습과 가중치 선택은 후속 작업이다.

1. 조판 작업자가 신뢰한 내장 모델을 가져와 측정한 후보와 남은 시간을 전달한다. 모델 부재, 추론 실패, 후보 ID 오류와 시간 초과는 규칙 지면으로 복귀한다. 실제 PDF의 줄 끝을 오프라인 테스트로 확인한다.
2. 웹과 네이티브에서 내장 모델을 선택하고 적용한다. 원격 주소·키 입력을 숨기고 설정에는 제공자 ID만 넣는다. 설정 확인과 PDF 수신 경로 양쪽에서 오류 사유를 확인한다.
3. 기존 외부 API, 네이티브 작업자와 전체 Docker 회귀 테스트를 실행한 뒤 양쪽 브랜치에 반영한다.
