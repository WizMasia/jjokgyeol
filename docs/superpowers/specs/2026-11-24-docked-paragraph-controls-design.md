# 하단 문단 서식과 AI 간격 조판

## 편집 화면

마크다운 원고에서 문단 서식을 조정하고, 같은 화면에서 규칙 교정본과 AI 교정본을 비교한다. 웹과 데스크톱은 같은 편집 화면과 서식 명령을 사용한다.

| 검토한 배치 | 문단 서식을 펼쳤을 때 |
| --- | --- |
| 상단 접이식 | 원고와 미리보기의 시작 위치가 함께 내려간다. |
| 오른쪽 3단 | 설정을 옆에 두고 계속 편집할 수 있다. 원고와 PDF에 쓰는 너비가 줄어든다. |
| 하단 고정 | 원고와 PDF의 시작 위치와 너비를 유지한다. 아래쪽 공간을 함께 내준다. |

사용자가 선택한 하단 고정 배치를 적용한다. **문단 서식**은 처음에 접고, 상단 도구 모음의 **문단 서식**과 패널의 **접기**로 열고 닫는다. 넓은 화면에서 원고와 PDF를 같은 높이에 나란히 배치하고 각자 스크롤할 수 있게 한다. 접고 펼칠 때 원고의 선택 범위와 표시 중인 교정본을 유지한다. 좁은 화면은 기존 세로 배치를 사용하고 하단 패널이 내용을 가리지 않도록 공간을 확보한다.

**AI로 조판**은 패널 상태와 관계없이 상단에서 사용할 수 있다. 조판을 갱신하는 동안에는 마지막으로 확인한 PDF를 보여준다. **규칙**과 **AI 결과**는 같은 미리보기에서 전환한다.

## 메뉴와 원고 도구

웹과 데스크톱의 편집기 안에 **파일**, **편집**, **서식**, **조판** 메뉴를 둔다. **파일**에서 쪽결 문서와 원고를 열고 저장하며, 가져오기를 지원하는 환경에서는 해당 명령을 노출한다. **편집**의 실행 취소와 다시 실행은 원고 편집 기록을 사용한다. **서식**에 굵게, 기울임, 문단 정렬, 문단 서식, 출판 설정과 문서 글꼴을 둔다. **조판**은 교정본 갱신과 PDF 내보내기를 제공한다. 원고의 조 제목 번호 고정은 기존 설정에 따라 나타난다. 메뉴와 도구가 같은 편집 명령을 호출하고 키보드로 접근할 수 있게 한다.

원고 위에는 **굵게**, **기울임**, **정렬**, **문단 서식**을 바로 노출한다. 굵게와 기울임은 선택 범위에 기존 마크다운 문법을 삽입하고, 이미 같은 표기가 적용된 범위에서 다시 실행하면 해제한다. 선택이 비어 있으면 원고로 포커스를 돌린다. 바깥의 원문과 개행을 보존하고 한 번에 실행 취소할 수 있게 한다. 문단 정렬은 기존 주석과 문단 대상 판정을 사용한다.

## 직접 조정과 저장

출판 설정에서는 문서의 **기본 문단 간격**과 **본문 기본 줄 간격**을 pt로 조정한다. 기본 문단 간격은 앞뒤 문단 모두 별도 간격값을 제공하지 않을 때 쓰인다. 저장 양식에서 생략하면 설치 설정의 기존 간격을 따르고, 0pt를 지정하면 문단 경계의 추가 간격이 없어진다. 글줄 기준선 사이의 줄 간격은 본문에서 출판 설정을 따르고, 제목에서는 기존의 제목 크기와 양식 규칙을 따르는 값이 기본이다.

하단 패널은 커서가 있는 최상위 본문 또는 제목의 원고 줄과 **위 여백**, **아래 여백**, **줄 간격**을 표시한다. 각각 양식 따르기, 직접 입력, AI 자동을 제공한다. 개별 줄 간격은 기존 쪽결 문단 주석을 확장해 표현한다. 여러 블록을 가로지르는 선택과 표·목록 내부에는 지원하는 본문 또는 제목을 선택하도록 안내한다. 목록 단계의 위아래 여백은 출판 설정에서 계속 지정할 수 있다.

앞 문단 아래와 뒤 문단 위가 같은 쪽에서 만나면 간격을 한 번만 계산한다. 수치가 둘이면 큰 쪽, 하나면 그 수치를 사용한다. 수치가 없는 자동 경계에서는 모델의 후보 선택을 사용한다. 페이지를 넘는 경계에는 문단 여백을 추가하지 않는다.

양식 수치는 기존 Style 검증을 거쳐 정수 sp로 저장한다. 개별 지정과 자동 여부는 마크다운에 기록하고, 양식 따르기는 해당 항목의 지정만 해제한다. 생략, 명시적 0, 자동과 직접 값을 파일 형식이 표현하는 범위에서 구별한다. 쪽결 문서(.jjok)를 웹과 데스크톱에서 왕복할 수 있게 하고, 기존 파일은 추가 설정을 사용하기 전과 같은 지면을 출력한다.

## AI 조판과 결과 고정

**AI로 조판**은 현재 원고·양식·모델 연결을 기준으로 교정본을 만든다. 기존 모델 줄바꿈과 함께, 개별 문단에서 선택했거나 양식에서 상속한 **AI 자동** 간격도 판단 대상으로 삼는다. 직접 입력값은 그대로 적용한다. 버튼을 눌러 조판한 뒤에는 AI 결과가 있으면 그것을 표시하고, 규칙 결과만 있으면 규칙 지면을 표시한다. 시작 시 미리보기, 일반 갱신, PDF 내보내기의 모델 사용 여부는 기존의 연결과 조판 설정을 따른다. 교정본 생성 자체는 저장된 원고나 양식을 수정하지 않는다.

기존 흐름과 같이 규칙 PDF를 먼저 확보하고, 검증된 모델 줄바꿈으로 이어서 조판한다. 위아래 여백에는 기존 경계 후보 선택을 사용한다. 줄 간격은 자동으로 지정되고 같은 쪽에서 비교할 글줄이 둘 이상인 본문과 제목에 대해 후보를 만든다. 규칙 간격과 그 주변의 안전한 후보를 출판 정책에서 정한다. 글자 크기, 실제 기준선 간격, 줄 수, 지면 여유, 문단 종류와 후보 ID를 모델에 전달한다. 선택을 현재 조판과 문단에 묶고, 제공한 후보 ID만 받아들인다. 기존 줄바꿈 전용 모델은 줄 간격에 규칙값을 사용한다.

선택값으로 재조판한 뒤 같은 쪽의 비교 가능한 기준선 간격이 선택값과 일치하는지 확인한다. 줄에 들어간 글자와 수평 배치는 이미 검증한 결과와 일치해야 한다. 판면과 제목·본문 묶음 규칙을 지키면 쪽 나눔과 전체 쪽 수가 달라질 수 있다. 쪽을 넘게 된 문단 경계는 적용된 값이 없는 것으로 표시한다. 수직으로 넘치거나 불필요한 빈 쪽이 생기거나 검증을 통과하지 못하면 직전에 검증된 PDF와 그 PDF의 적용값으로 대체한다. 모델 실패와 기한 초과에도 같은 복구 경로를 쓰며 이미 검증된 줄바꿈과 직접 지정값을 보존한다. 요청 수와 실행 시간은 기존 조판 한도를 공유하고, 한도 안에서 처리하지 못한 자동 항목은 규칙값을 유지한다.

하단 상태줄은 조판 중과 마지막 교정본의 상태를 함께 표시한다. 모델을 요청한 조판의 응답을 기다리는 동안에는 **AI 조판 중**을 표시한다. 응답에 따라 **AI 조판 완료**, **일부 AI 적용**, **규칙 조판 완료**와 확인 가능한 이유를 표시한다. 실패하면 기존 PDF를 보면서 오류를 확인할 수 있다. 이전 작업에서 늦게 온 응답은 새 작업의 상태나 미리보기에 적용하지 않는다.

하단 패널에서 표시 중인 교정본의 측정값을 설정 옆에 보여준다. 적용할 경계가 없으면 **경계 없음**, 이전 원고의 교정본이거나 측정값이 없으면 **갱신 후 확인**을 표시한다. 한 문단의 실제 줄 간격이 줄마다 다르면 **줄별로 다름**을 표시한다. 원고·양식·연결과 선택한 문단에 대응하며 하나의 수치로 재현 가능한 현재 AI 결과에 **고정**을 제공한다. 누른 항목을 정수 sp로 원고에 기록하며 나머지 자동 설정은 유지한다. 고정은 실행 취소할 수 있는 원고 편집이고, 이후 교정본에는 갱신이 필요하다고 표시한다.

## 검증 기준

- 웹과 데스크톱에서 하단 패널을 접고 펼칠 때 원고와 PDF의 상단 및 너비가 유지되는지 확인한다. 키보드로 메뉴, 강조, 정렬, 조판과 고정을 실행한다.
- 이전 양식, 0pt, 한쪽 직접 값과 자동 경계, 양쪽 직접 값, 개별 줄 간격과 상속값을 실제 PDF의 기준선과 글자 좌표로 비교한다. 여러 쪽에 걸친 문단, 제목 틀, 목록, 표와 각주도 확인한다.
- 고정 응답 모델로 후보 선택, 규칙·AI 지면 전환, 적용값 고정을 검증한다. 틀린 후보와 모델 미연결, 기한 초과, 늦은 응답에 마지막으로 검증된 결과가 유지되는지 확인한다.
- 마크다운과 .jjok를 저장해 다시 열고, 양식 JSON의 필드 생략과 명시 값 및 개별 문단 편집의 원문·개행·실행 취소가 보존되는지 확인한다.
